# Basic Network Port Scanner

A Python-based network port scanner that scans common ports of a target website or IP address to identify open ports.

## Features
- Scans common ports
- Detects open ports
- Supports website and IP scanning
- Built using socket programming

## Technologies Used
- Python
- Socket Programming

## How to Run

1. Clone repository

git clone https://github.com/sapna271708/Basic-Port-Scanner.git

2. Run project

python port_scanner.py

3. Enter website or IP address

Example:
google.com
